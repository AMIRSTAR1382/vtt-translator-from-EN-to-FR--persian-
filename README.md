VTT Translator (EN to FA) 🌍

Convert your English VTT subtitles to Persian in just 1-3 minutes!
این ابزار ساده زیرنویس‌های VTT انگلیسی شما رو به فارسی ترجمه می‌کنه، بدون نیاز به API Key و با استفاده از Google Translate (غیررسمی).

🚀 How to Use:

Download the vtt_en2fa_gui.py file.

Run the script:

python vtt_en2fa_gui.py


Select your English .vtt file from your system.

Wait for the translation to complete (usually takes 1-3 minutes).

Get your Persian-translated VTT file saved in the same folder.

🚀 چگونه استفاده کنیم:

فایل vtt_en2fa_gui.py را دانلود کنید.

اسکریپت را اجرا کنید:

python vtt_en2fa_gui.py


فایل VTT انگلیسی خود را از سیستم انتخاب کنید.

منتظر بمانید تا ترجمه تکمیل شود (معمولاً 1-3 دقیقه طول می‌کشد).

فایل VTT ترجمه‌شده به فارسی در همان پوشه ذخیره می‌شود.

📦 Install Dependencies:

Before running the script, make sure to install the required Python package:

pip install deep-translator

📦 نصب وابستگی‌ها:

قبل از اجرای اسکریپت، مطمئن شوید که پکیج پایتون مورد نیاز را نصب کرده‌اید:

pip install deep-translator

🌟 Key Features:

No API Key Needed: Works seamlessly using Google Translate without the hassle of setting up API keys.

Fast & Easy: Translation usually takes between 1-3 minutes for an average file.

Simple GUI: Just click and select your file — no complicated steps!

🌟 ویژگی‌های کلیدی:

بدون نیاز به API Key: این ابزار به‌راحتی با استفاده از Google Translate کار می‌کند، بدون نیاز به تنظیم API Key.

سریع و آسان: ترجمه معمولاً بین 1 تا 3 دقیقه برای هر فایل متوسط طول می‌کشد.

رابط کاربری ساده: فقط کافی است فایل خود را انتخاب کنید — بدون مراحل پیچیده!
